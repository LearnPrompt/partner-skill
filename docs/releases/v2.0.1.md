# Partner 2.0.1

Partner 2.0.1 hardens the Claude Deep Reasoner path after a real Fable 5
planning run authenticated successfully, explored the repository through
multiple subagents, spent `$6.57`, and then ended with a stream-idle error
before returning a plan.

## What Changed

- The outer host now owns repository discovery and supplies a machine-checked
  planning packet of at most 24,000 characters.
- `scripts/run-claude-plan.py` resolves the exact configured role/model/effort,
  then runs Claude in safe mode with Chrome, tools, custom agents, and
  subagents disabled; the bounded prompt is supplied on stdin, not argv.
- Default runtime guards are 10 minutes wall time, 3 minutes without a valid
  JSON stream event, process-group termination, bounded stream/output/log
  sizes, and `$2` through Claude CLI's `--max-budget-usd`.
- Every run keeps sanitized events, visible text, exact limits, session id,
  result/cost metadata, and a same-session recovery command.
- Authentication failures, upstream idle, local idle, wall timeout, budget
  stop, attempted tool use, and protocol errors remain distinct.
- A nominally successful CLI result must satisfy the eight-section plan output
  contract; conversational or incomplete output fails without creating a plan.
- Successful runs must report the requested session id and exact configured
  model, exit zero, and retain requested/observed values plus the runner hash
  for audit.
- Identity changes invalidate inherited verification, common bearer/JWT,
  password, GitHub/GitLab and provider tokens are rejected or redacted, and
  concurrent output paths cannot overwrite an existing plan.
- Another role or model is never selected automatically.

## Input Contract

The required packet and recovery flow live in
[`references/bounded-planning.md`](../../references/bounded-planning.md).
Existing one-line setup smoke remains a configuration check, not evidence that
repository-scale planning is reliable.

## Verified Showcase Run

The final release-candidate loop used the exact configured
`claude-fable-5`/`xhigh` identity with no fallback:

- a fresh bounded attempt reached the 180-second accepted-event idle limit,
  exited as `idle_timeout`, created no plan, and retained same-session recovery;
  Claude CLI emitted no final cost event, so its cost remains `unknown`;
- the exact same session resumed successfully with a valid eight-section plan
  and reported `$0.382695`;
- a separate final fresh candidate returned a valid plan with exact
  model/session, return code zero, matching packet/runner hashes, and reported
  `$0.45282`;
- the complete local suite passed 102 tests and the independent final Judge
  reported no P0, P1, or P2 findings.

These are per-run Claude CLI cost results, not an end-to-end token-savings
claim. The v2.0.0 failure that motivated this release reported `$6.57` before
ending without a plan.
